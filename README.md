🏓 Pong – Single Player with AI

Python • Pygame

A single-player Pong game built in Pygame, featuring an AI opponent with adjustable difficulty levels and realistic ball physics.

🧠 What I Learned / Practiced

Simple AI behaviour and decision-making

Game state management

Collision detection and physics basics

Difficulty scaling

Working with sound generation

Clean separation of game logic and rendering

✨ Features

Single-player Pong against an AI opponent

Difficulty levels:

Beginner

Intermediate

Expert

AI difficulty controlled by:

Paddle speed

Reaction delay

Accuracy (intentional error)

Ball physics where:

Ball angle depends on paddle hit position

Ball speeds up over time

Countdown before each serve

Pause functionality

HUD showing score, difficulty, and controls

Procedurally generated sound effects (no external audio files)

🖥️ Tech Stack

Python

Pygame

▶️ How to Run
pip install pygame
python main.py
📌 Why This Project

This project was built to explore basic game AI and physics in a controlled environment. The focus was on making the AI feel fair and beatable rather than perfect, while keeping the code readable and easy to extend.
